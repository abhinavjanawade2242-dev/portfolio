## 🛠️ Local Development (Offline Setup)

To run or modify the portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abhinavjanawade2242-dev/portfolio.git
   cd portfolio
   ```

2. **Open directly**:
   - Double-click `index.html` to open it in Chrome, Edge, or Safari.

3. **Or run with a local lightweight server**:
   ```bash
   # Python 3
   python -m http.server 5000

   # Or Node.js
   npx serve .
   ```
   Then open `http://localhost:5000` in your browser.
